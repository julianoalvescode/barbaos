# Changelog

## BarbaOS 1.0 (2026-11-16)

- **Full SD card image for Rufus** (based on dArkOS4Clone 20261008)
- BarbaOS boot logo and "Loading..." screen when games start
- **BarbaDrop**: Wi-Fi downloads from a server on your PC, with search, queue, extraction and boxart
- **BarbaDrop server** for Windows/macOS/Linux (`pc/barbadrop_server.py`)
- **BarbaOS Branding**: `BarbaOS` hostname and a branding report
- `install.ps1` installer with automatic backups
- `-FixAudio` option for the R36S V20 board (2025-05-18)
- EpicAeolus theme included
- Boxart scripts (libretro-thumbnails) in `pc/`
- Project website on GitHub Pages
